# ComputAI 介面設計規則

適用於終端機（live、`--once`）和網頁（`--web`）的 `cyber` 主題；`classic` 主題只沿用「資訊」那一半的規則。

一句話：**cyberpunk 是一台冷靜、精準的儀器，不是霓虹招牌。** 平常安靜，有事才亮；每個顏色都有意思；
畫面最上面先回答「現在有沒有事」。

## 參考來源

- [Minerva](https://github.com/aifred0729-TW/Minerva) 的 `docs/DESIGN_LANGUAGE.md` 和 `components/Instrument.tsx`
  （AGPL，只參考原則，沒有複製程式碼）：明確拒絕「硬核 HUD」（切角、掃描線、括號編號、hex 位址、淡白字），
  狀態用「字＋點」、面板是「標題列／主體／來源列」三段、顏色依用途命名而不是依色相命名。
- Cyberpunk 2077 介面評論（[Interface In Game](https://interfaceingame.com/articles/cyberpunk-2077-ux-ui-critique/)）：
  整片同一個顏色、什麼都在閃，等於沒有重點；狀態只靠顏色分不出來。
- Jayse Hansen 談電影介面（[Pushing Pixels](https://www.pushing-pixels.org/2012/06/01/the-craft-of-screen-graphics-and-movie-user-interfaces-conversation-with-jayse-hansen.html)）：
  每個圖形都要有目的、大量留黑讓重點浮出來。
- [scifiinterfaces 對攻殼機動隊的評分](https://scifiinterfaces.com/2013/08/26/report-card-ghost-in-the-shell/)：
  半透明疊層傷害閱讀，顏色要拿來換對比。
- [eDEX-UI 的可讀性問題](https://github.com/GitSquared/edex-ui/issues/464)：好看但不能每天用。

## 1. 先回答「現在有沒有事」

畫面最上面是一條**總結列**，由同一份判斷（`verdict()`）算出：

| 等級 | 字 | 什麼時候 |
|---|---|---|
| 正常 | `● 一切正常` 綠字 | 沒有額度 ≥ 80%、沒有警示 |
| 注意 | `注意` 琥珀底黑字 | 有額度 ≥ 80%、模型佔著記憶體沒在用、超過預算 |
| 要處理 | `要處理` 紅底黑字 | 額度用完、機器連不上、雲端 GPU 閒著還在計費 |

後面接最嚴重那一件事的白話句子（「Codex 每週額度用完，5h08m 後重置」）和「另外還有 N 件」。
**反白色塊整個畫面只准出現在這裡**——它是最大聲的東西。

## 2. 顏色：依用途命名，不依色相

| 用途 | 終端機 / 網頁 | 只能用在 |
|---|---|---|
| `text` 內文與數值 | `#e6e8eb` | 所有一般文字。不用純白（黑底純白會暈開） |
| `meta` 次要資訊 | `#9aa1ab` | 單位、來源列、標籤旁的補充。**不准拿來寫主要內容** |
| `line` 框線 | `#3a3f47` | 框線、分隔線、空的長條格 |
| `brand` 品牌／互動 | 青 `#67e8f9` | 品牌字、區段標題、可點的東西、一般用量長條 |
| `ok` 正常 | 綠 `#4ade80` | 「推論中」「一切正常」「回本」 |
| `warn` 注意 | 琥珀 `#fbbf24` | 額度 ≥ 80%、閒置佔記憶體、沒設月費 |
| `fail` 故障／用完 | 紅 `#f87171` | 額度用完、連不上、超過預算、閒置計費 |

- **額度是第二大聲的東西**：用背景色塗滿整格的粗量表（不是細線），後面是粗體百分比，量表上一條白線 `┃`
  標出週期過了多久。量表只畫圖、不放字，所以不算「反白字塊」；黑字色底的字塊仍然只在總結列。
- 長條的顏色**不是漸層**：一般用 `brand`，額度到 80% 變 `warn`、到 95% 變 `fail`；CPU、GPU 使用率是工作量不是問題，永遠 `brand`。
- 溫度 ≥ 80°C `warn`、≥ 90°C `fail`，其他是 `text`。
- 不准用低透明度的色塊當底（黑底上會變成髒的暗色），顏色只放在字、框線和長條上。
- 品牌色不兼任語意：青色永遠不代表「好」或「壞」。

## 3. 文字

- 數值：`text` 粗體，等寬數字。標籤：`text` 一般字重，英文大寫加寬字距（網頁）。
- 次要資訊才用 `meta`；終端機**不用** SGR 2（dim），很多終端機會把它畫成幾乎看不見的灰。
- 網頁字級只有六階：11（標籤）、13（內文）、16（強調）、26（讀數）、32、44。
- 全大寫只用在短標籤，句子保持原本大小寫；主機名、模型名保持原樣。

## 4. 面板 = 標題列／主體／來源列

- **標題列**：左邊說「這是什麼」，右邊一個狀態字說「現在怎樣」（`2 台在線`、`1 個額度用完`）。
- **主體**：先摘要、再細節。
- **來源列**：數字從哪來、多新（`SSH · 4 秒前`、`價格：prices.ini，2026-10-03 查`）。沒有來源的數字不可信。
- 框線是 1px 細線、顏色 `line`；只有面板裡有 `fail` 的事情時框線才變紅。

## 5. 狀態一定是「字＋點」

`● 推論中`、`○ 閒置`、`已用完`、`連不上`。點只是裝飾，意思在字上，色盲和單色終端機也讀得懂。

## 6. 裝飾的配額

可以：細框線、品牌字的一點點青、網頁上**只有總結列**可以有一層柔光。

不可以：掃描線、glitch、閃爍、整片光暈、切角、半透明疊層、`// 0x0042` 這種假技術字、
`▓▒░` 漸層、熱度漸層長條、為了好看而加的走勢圖。

## 7. 終端機相容

- 只用 7 個角色色，256 色和 truecolor 都清楚；`NO_COLOR`、`--ascii` 時意思完全不靠顏色。
- 寬度不夠時句子折行、標頭在「·」之間換行，**不裁掉**重置時間這類關鍵資訊。
