## 相容性與隱私 review

由開發 agent 自行 review；沒有獨立第二位 reviewer。

- 新月報入口只同步支援的本機用量來源，不觸發 SSH、雲端 API、方案設定或更新查詢。
- 選單本身不讀用量、不建帳本、不連線；監控／其他功能依選項開始執行。
- 製卡模板只包含彙總，分享 JSON 只包含目前選定的區間；原始 session ID、專案路徑、機器名稱及對話不包含於分享匯出。
- 本機 creator 以暫存檔原子寫入，POSIX 權限 600；Web creator 沿用 Host／CSP 邊界，既有帳本以唯讀模式開啟。
- proxy 請求只記用量、時間、結果、模型及標記；不記 prompt、回應、query string、headers 或錯誤內容。
- token 累計沿用正規化規則；推理不重算，快取可重複讀取，缺紀錄不冒充零。
- beta.2 匿名 session、補填邊界與舊格式相容性回歸保持通過。沒有加入 credential 讀取或新的常駐 agent。
- Windows 安裝器將不存在的使用者 PATH 轉成空字串，避免第一次安裝呼叫 null 的 `TrimEnd`。

## 發佈包與實機限制

發佈包以已提交程式、安裝器、製卡快捷入口、公開文件／示範圖片與授權的明確清單建立。
不納入 NIGHT_LOG、研究筆記、使用者設定、金鑰、帳本、個人報告或對話 log。
每個獨立 asset 附 SHA-256，ZIP 內也包含核心執行檔的校驗清單；先驗證草稿附件，再公開 prerelease。

本次未在 Windows 原生環境、真實 GUI 點擊／PNG 下載、真實雲端帳號或手機驗收。
沒有新增本地模型推論負載或重啟使用者既有服務；本地計數與其他 parser 沿用 fixture 和既有實機驗證紀錄。
